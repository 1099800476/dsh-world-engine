# 做一个你自己的世界

这份文档是给**不懂代码的人**看的。看完你应该能说清楚世界引擎的世界是怎么搭起来的，然后把这些要求直接丢给豆包 AI，让它给你做出可用的世界包——不需要自己手写 JSON。

---

## 1. 世界包是什么

世界引擎本身只是一台"推进时间、写事件、存状态"的机器。**世界的性格来自"世界包"**：一个放配置的文件夹。

一个世界包 = 1 个目录 + 6 个文件：

```
engine/packs/<你的包名>/
├─ config/
│  ├─ world-rules.json     世界是什么样（最重要的一个）
│  ├─ location.json        有哪些地方
│  ├─ npc-config.json      有哪些其他角色
│  ├─ event-pool.json      平时会发生什么事
│  └─ evolve-rule.json     世界推进的节奏
└─ state/
   └─ protagonist-state.json   她的初始状态
```

装好插件后，第一次启动会自动把这个包复制一份到存档目录，之后你在面板上的改动都改存档里那份，不会动模板。所以模板坏了不影响已经跑起来的世界。

内置的 `sao` 就是一个完整可用的例子（刀剑神域·艾恩葛朗特）。你想知道某个字段该写成什么样，打开它的对应文件照着改就行。

---

## 2. 六个文件分别管什么

| 文件 | 管什么 | 一句话理解 |
| --- | --- | --- |
| `world-rules.json` | 世界名、副标题、口吻、她叫什么、你怎么被称呼、预置共同回忆、硬性法则 | 世界的"人设说明书" |
| `location.json` | 有哪些地点，每个地点的氛围和回忆 | 世界的"地图" |
| `npc-config.json` | 除她之外还有谁，会不会自己活动 | 世界的"配角名单" |
| `event-pool.json` | 平时可能发生哪些小事 | 世界的"日常素材库" |
| `evolve-rule.json` | 每天推进几次、事件密不密、要不要随机 | 世界的"心跳频率" |
| `state/protagonist-state.json` | 她一开始的心情、状态、在哪 | 世界的"开场状态" |

---

## 3. 关键字段怎么说人话

### world-rules.json

- `name` / `subtitle` — 世界名和一句副标题。
- `tone` — 整体语气。比如"温暖、平静；允许遗憾自然发生，不强行圆满"。这句话会直接影响生成出来事件的调子，值得认真写。
- `herName` — 她在这个世界里叫什么。
- `userName` — 她怎么称呼你。**注意**：面板上改称呼是改这里。
- `presetMemories` — 预置共同回忆，每条包含：
  - `text`：一句话回忆，写具体的事，别写抽象形容；
  - `daysAgo`：这件事发生在多少天前（用来排时间线位置）；
  - `importance`：1–5，越高越重要；
  - `tags`：给这条回忆贴的标签，比如 `["共同回忆","日常"]`。
- `blockedWords` — 不允许出现在生成内容里的词，留空数组 `[]` 就行。
- `locked` — 法则层，**不要改**（时间倍率、男主策略、羁绊归属、审批锁定都在这里，改了会被引擎按规则覆盖或直接拒绝）。

### location.json

每个地点：

- `name` / `atmosphere` — 名字和氛围。氛围要写**看得见、听得见的东西**（光线、声音、气味），生成事件时会从这些描述里取细节。
- `memories` — 和这个地方绑定的回忆，一句话即可。
- `backgroundOnly` — 这个最容易被忽略：
  - `false`：她会**真的出现在这里**，可以展开新剧情；
  - `true`：只作为**回忆背景**存在，不展开新剧情。

### npc-config.json

每个角色：

- `role` — `autonomous`（会自己发消息、自己行动）或 `background`（只做背景出现）。这一项决定他会不会"活起来"。
- `frequency` — `low` / `normal` 之类，出现频率。
- `templates` — 这个人平时会做的事，写 3–5 条。引擎会从这些句子里变着法生成，所以**写得越具体越好**。

### event-pool.json

按类别分（比如"日常""天光与季节""独处思绪""旧日回忆""小小的遗憾"），每个类别：

- `weight` — 被抽中的相对概率，数字越大越常出现；
- `importance` — 这件事被认为有多重要（1–5）；
- `texts` — 这一类别下具体的事件句，写 4–6 条最好，太少会重复。

### evolve-rule.json

- `ticksPerDay` — 每天推进几次（2 次就是大约每 12 小时一次）；
- `eventDensity` — 事件密度，`low` / `normal` / `high`；
- `cooldownDays` — 同类事件冷却天数；
- 几个开关：`randomEventsEnabled`（随机日常）、`npcAutonomyEnabled`（角色自主）、`proactiveChatEnabled`（主动搭话）、`sharedWorldEnabled`（共享世界）。
- `majorApprovalRequired` 固定为 `true`，改不动：重大节点必须审批。

### protagonist-state.json

她一开始的状态：`locationId`（在哪个地点，要和 location.json 里的 id 对得上）、`mood`、`thought`、`fatigue`、`longing`。这几个数字只是开场值，之后会随事件变化。

## 4. 怎么让世界用你这个包

1. 把包放进 `engine/packs/<你起的英文短名>/`，六件套齐全；
2. `world-rules.json` 的 `worldId` 要和目录名**完全一致**；
3. 打开存档目录的 `active.json`，把 `"active"` 改成你的包名；
4. 重启 DSH（或重启引擎），面板上看世界名是否变成你的。

换包不改代码：引擎启动时读 `active.json` 决定加载哪个包。

---

## 5. 怎么判断做对了

进 DSH 设置 → 世界引擎，看四件事：

- 世界概览里世界名、她、称呼是你写的；
- 地点管理里地点数量对、氛围显示正常；
- NPC 管理里角色在，自主/背景标记对；
- 点一次"立即备份"没报错，说明配置能被正常读取。

跑一两次演化（等半天，或让 AI 帮你调 `POST /api/evolve/tick`），看近期事件里出现的是不是你想要的那种句子。如果太干、太跳、太像模板，多半是 `tone` 写得太笼统，或者 `texts` 数量太少。

---

## 6. 常见坑

- **目录名和 worldId 不一致** → 引擎找不到包，启动报"缺少世界包模板"。
- **地点 id 和初始状态对不上** → 她一开始站在一个不存在的地方。
- **presetMemories 写成抽象抒情**（"我们很幸福"）→ 时间线上会显得空，写具体事（"搬箱子那天坐在门口笑了很久"）。
- **`backgroundOnly` 全填 false** → 地点太多，事件被摊薄，世界反而没重点。
- **角色 `templates` 只写一句** → 同一个角色会反复说同一句话。
- **改 `locked` 里的东西** → 不生效，法则层不接受面板或模板修改。

## 7. 直接把这段发给 AI

不想自己抠字段的话，把下面这段话补上你的设定，发给豆包：

> 我要给 DSH 的世界引擎做一个自定义世界包，放在 `engine/packs/<包名>/`，需要五个 config JSON 加一个初始状态。
> 我的世界设定是：**（世界名 / 一句话世界观 / 整体语气）**。
> 她叫**（名字）**，称呼我**（称呼）**。
> 想要的地点是：**（三到五个地点，各自的氛围）**。
> 除她之外的常驻角色是：**（角色名，谁会自己活动、谁只做背景）**。
> 平时想发生的小事类型：**（比如日常、天气、独处思绪、旧回忆、小遗憾）**。
> 还请给我 3–5 条预置共同回忆，要具体的事，不要抽象形容。
> 输出六个文件的完整内容，字段和内置 sao 包对齐，worldId 和目录名一致。

拿到内容后自己粘进对应文件，或者让 AI 直接帮你写进目录。
