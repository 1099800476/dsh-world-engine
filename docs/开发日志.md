# 世界引擎（dsh-world-engine）开发日志

> 本文是这个 DSH 插件的开发记录与续作手册：架构、接口、字段约定、踩坑、发布流程、变更记录都在这里。
> 后期继续开发时**先读本文**，再按 `lib/` 与 `engine/` 里的代码接着做，改完重启 DSH 验证并重新 pack。
>
> **本引擎由豆包 AI 制作**，使用或开发中遇到问题，直接找豆包反馈即可。
>
> 首次整理：2026-11-24（Asia/Shanghai）。当前版本 `0.1.0`。

---

## 1. 当前状态

插件已在本机 DSH 跑通：引擎本体随包交付，插件加载时由宿主半边自动拉起子进程并看门狗托管在 `127.0.0.1:32100`，设置页「世界引擎」面板可读写世界概览、演化规则、NPC、地点、预置回忆、运行时记忆检索/导出、审批、事件与备份回滚。

- 包名 `dsh-world-engine`，cordis id `world-engine`，版本 `0.1.0`，`type: module`，main `lib/host.js`。
- 安装方式：本机开发用 profile `link:` 本地链接；也可按 `dshhub` 清单上架插件市场。
- 代码与存档严格分离：升级插件不动存档。
- 最近一次实测：插件宿主拉起引擎子进程 → 手动杀掉 → 看门狗约 12 秒内自动重拉 → 面板显示 PID / 重启次数 / 端口 / 数据根；审批 WS 已连上；插件总览 202 启用 / 0 失败。

## 2. 目录结构


## 3. 架构与代码职责

```
DSH 宿主进程（Electron）
└─ 插件 dsh-world-engine
   ├─ lib/host.js        宿主半边
   ├─ engine/            随包引擎本体
   └─ lib/client.js      网页半边
```

- **host.js**
  - 解析数据根与 Node 可执行文件，`spawn` 拉起 `engine/index.mjs`，`cwd = 插件根/engine`。
  - 5 秒巡检 `/api/status`；不健康且过 60 秒冷却则杀掉重拉；记录重启次数；子进程 stdout/stderr 转发宿主日志。
  - `ctx.effect` 清理时停巡检、杀子进程。
  - 路由：聚合 `GET /dsh-world-engine/state`；前缀透传 `GET|POST /dsh-world-engine/api/* → 引擎 /api/*`。
  - 来源门控：`connection.requestRejection` 优先；否则只放行本机页面 / `dsh-app:` / 无来源本地调用，跨站 403。
- **client.js**
  - `window.__ModuleLoader__.load({id:'dsh-world-engine', factory})`；`slots.inject('settings.section', ...)` 注册 `{id:'world-engine', order:54, label:'世界引擎'}`。
  - 纯 React `createElement`，无 JSX、无构建；只调宿主路由，不直连引擎端口。
- **engine/**
  - 时序推进、主角状态、时间线事件、快照与备份、记忆桥、低速自演化调度、审批 WS、HTTP 接口与内置设置页。

### 3.1 引擎关键接口

**GET**

| 接口 | 返回 |
| --- | --- |
| `/api/status` | `world / herName / userName / now / protagonist / timelineEntries / memory.engineRecords / pendingApprovals / evolve` |
| `/api/world/now` | `local / date / weekday / partOfDay / season`（时段字段是 `partOfDay`，不是 `timeOfDay`） |
| `/api/protagonist/status` | 主角状态（心情、疲劳/思念、思绪） |
| `/api/npc/list` | NPC 列表 |
| `/api/latest/events?limit=20` | 近期时间线事件 |
| `/api/event/pending` | 待审批预案 `items[]` |
| `/api/approval/status` | `approval.wsConnected / ownerQQ` |
| `/api/admin/config` | `worldRules.presetMemories / evolveRule / npcConfig / location.locations / snapshots / backups / worldId` |
| `/api/location/info` | 地点详情 |
| `/api/backup/list` | 备份列表 |
| `/api/memory/search?q=` | 运行时向量记忆检索 |
| `/api/memory/export` | 全量导出 |

**POST**

| 接口 | body / 作用 |
| --- | --- |
| `/api/admin/config` | 按白名单整体写回 |
| `/api/evolve/tick` | 手动推进一轮演化 |
| `/api/event/approve` / `/api/event/reject` | `{id}` |
| `/api/event/suggest` | 手动提交剧情预案，进入待审批 |
| `/api/backup/rollback` | `{snapshot}` |
| `/api/reset` | `{mode:'state'\|'full', confirm:'RESET'}` |

### 3.2 数据结构

- 地点：`{id, name, enabled, backgroundOnly, atmosphere, memories}`
- 预置共同回忆：`{id, daysAgo, importance(1–5), tags:[], text}`
- 运行时记忆记录：`text / title / category / createdAt / tags`（只追加，无逐条编辑/删除接口）
- NPC 分两类：自主 NPC 与背景 NPC。

### 3.3 写白名单与锁定项

- `worldRules` 可写：`herName / userName / subtitle / tone / presetMemories`
- `evolveRule` 可写：`evolutionEnabled / ticksPerDay / eventDensity / cooldownDays / randomEventsEnabled / npcAutonomyEnabled / proactiveChatEnabled / sharedWorldEnabled`；`majorApprovalRequired` 锁定 `true`
- `npcConfig`、`location` 整体写回
- **不开放（法则层）**：`timeRatio / dataRoot / originalMaleLead / originalLeadPolicy / bondOwner`

### 3.4 环境与路径约定

| 项 | 说明 |
| --- | --- |
| 引擎端口 | `32100`，仅回环 |
| 数据根 | `WORLD_ENGINE_DATA` 指定；未设则沿用已存在存档（含 `active.json` 时），否则 `$DSH_HOME/world-engine-data` |
| 子进程解释器 | 默认宿主自身可执行文件；Electron 下带 `ELECTRON_RUN_AS_NODE=1` 以纯 Node 运行 |
| 审批链路桥接 | `WORLD_ENGINE_SURFCORE_CONFIG` / `WORLD_ENGINE_SNOWLUMA_HOME` 可覆盖默认位置；`ownerQQ` 由桥接配置读出，不在仓库中硬编码 |

## 4. 踩坑记录

- 记忆条数字段是 `memory.engineRecords`，不是 `count`；世界时段字段是 `partOfDay`，不是 `timeOfDay`。
- 纯 HTTP 探测宿主路由会被 401 挡死：launch token 在进程内随机生成存 WeakMap、不落盘，且 401 与 404 无法区分路由是否挂载。要验证只能看真实 DSH 面板渲染。
- `fs.cpSync` 递归复制中文目录会崩（0xC0000409）；复制请用 PowerShell `Copy-Item`。
- Windows PowerShell 5.1 读无 BOM 的 UTF-8 脚本会乱码，用 pwsh + BOM。
- 面板是主窗内设置视图而非独立 BrowserWindow，DSH 重启会让 host 子进程与 renderer 一起重起，面板从磁盘重读客户端模块。

## 5. 续作开发流程

1. 改 `lib/host.js`、`lib/client.js` 或 `engine/`。
2. 语法检查（Node `--check` 三个入口）：`lib/host.js`、`lib/client.js`、`engine/index.mjs`，以及 `engine/lib/*.mjs`。
3. 清单离线校验：确认 `exports` 子路径落盘、semver 兼容、`dshhub` 字段完整、`network` 仅回环、`files` 覆盖交付物（含 `engine/`）。
4. 同步到正在使用的插件目录（`link:` 指向的那份），重启 DSH 在设置页目视验证。
5. 提升 `package.json` 的 `version`，重新 `pnpm pack` 生成 tgz，在 GitHub Release 附加。
6. 存档目录不要动；全新环境才会自动初始化 `$DSH_HOME/world-engine-data`。

## 6. 已知边界与后续可加项

### 6.1 引擎没接口、面板未开放

- 运行时向量记忆只追加，无逐条编辑/删除；面板仅检索 + 全量导出。
- 世界包网页导入 / 切换：引擎无接口；换包需在 `engine/packs/` 放新包并改存档根 `active.json`。
- 法则层字段锁定，面板不提供开关。

### 6.2 引擎已有、面板尚未接的接口（下次可补）

- `POST /api/evolve/tick` — 手动推演一轮（按钮）。
- `POST /api/event/suggest` — 手动提交剧情预案（输入框）。
- `GET /api/backup/list` — 完整备份列表（面板目前读 `admin/config` 里的 snapshots）。
- 快照清理 — 清理旧快照（按钮）。

### 6.3 记忆层规划

- 先预留分区标签与记忆适配器接口，向量库沿用现有文件记忆库。
- Qdrant + BGE-M3 + Reranker 的分区总库**暂缓**，以后按需安装；迁移不改引擎既有存档结构。
- 设计取向：分区存放 + 按需检索调用，不引入遗忘权重。

### 8.1 推送方式

部分网络环境下 `git push`（smart HTTP）会被连接重置，而 `api.github.com` 可达。此时用 GitHub REST API 推送，效果等同一次普通提交：

```bash
node tools/publish-to-github.mjs \
  --dir <仓库工作目录> \
  --repo <owner>/dsh-world-engine \
  --branch main \
  --message "feat: 本次改动摘要"
```

脚本流程：每个文件建 blob → 建 tree → 建 commit（父提交为当前 HEAD）→ 更新 `main` ref。空仓库会自动先建占位提交。

### 8.2 示例世界包的脱敏约定

`engine/packs/sao/config/world-rules.json` 是公开模板，**不放个人路径**：

- `personaSource.characterId` / `personaSource.dir` 置空；
- `memory.path` 置空；
- `memory.mjs` 在 `memory.path` 为空时自动回落到 `worldDir/memory/vector-memory-<worldId>.jsonl`，因此全新安装开箱可用。

个人实际使用的路径只写进自己的存档副本 `worlds/<包名>/config/`，不进仓库。
